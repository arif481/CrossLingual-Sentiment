Cross-lingual sentiment analysis for Bengali

Md Arifuzzaman Code Run in Colab Metrics

XLM-RoBERTa base fine-tuned only on English movie-review sentences scores 67.8 macro-F1 on Bengali social media comments. Fine-tuned on 100 Bengali comments instead, it scores 73.7, and on all 9,681 it scores 87.4. Starting from the English model, or adding the English data to the Bengali, moves the Bengali score by less than 2 points at every data size tested.

Every number on this page comes from runs on a free Colab T4. Each run's metrics, including confusion matrices for both test sets, are committed in the repository.

Setup

The task is binary: positive or negative.

  • English: SST-2 from GLUE, sentences from movie reviews. 63,981 sentences for training and 3,368 held out for validation. SST-2's test labels are not public, so its 872-sentence validation split is the test set.
  • Bengali: SentNoB (Islam et al., Findings of EMNLP 2021), comments from Bangla social media. The paper's train, validation and test files with neutral comments removed: 9,681, 1,213 and 1,225 comments, 53% positive.

Each model is trained on English, Bengali or both, and tested on both test sets. The best epoch is chosen on validation data from the training language only, so the zero-shot model never sees a Bengali label. Training runs for up to 4 epochs at learning rate 2e-5 and batch size 32, with sequences cut at 128 tokens and early stopping on validation macro-F1. The baseline is TF-IDF over unigrams and bigrams (50,000 features) with logistic regression.

Zero-shot transfer gets part of the way. The English-only model is 32 points ahead of TF-IDF on Bengali, which labels 1,216 of the 1,225 comments positive, and 19.6 points behind training on Bengali. Its mistakes mostly go one way: it gets 531 of the 571 negative comments right but calls 342 of the 654 positive ones negative.

Adding 63,981 English sentences to the Bengali training set moves Bengali F1 from 87.4 to 87.9. With 1,225 test comments the 95% confidence interval is about ±1.9 points, so that is not a measurable gain. English barely moves either (92.1 against 92.0). Transfer runs the other way too: the Bengali-only model scores 76.9 on English without seeing an English example.

For TF-IDF, adding English costs 2.5 points on Bengali. Under the 50,000-feature cap the combined vocabulary keeps 3,413 Bengali n-grams, against 35,256 when training on Bengali alone.

A hundred Bengali labels beat all of SST-2

The learning curve asks how many Bengali labels it takes to match English transfer, and whether starting from the English model helps when Bengali data is scarce. XLM-R was fine-tuned on random subsets of the SentNoB training set, from 100 comments to all 9,681, starting either from XLM-R itself or from the English-only model above. Each size was run with seeds 42, 43 and 44. Each seed draws its own subset, smaller subsets are nested inside larger ones, and both starting points see the same comments. A few hundred examples leave too little for a validation set, so every run trains for 4 epochs or at least 200 steps, whichever is longer (batch size 16, learning rate 2e-5), and the final model is tested.

100 Bengali comments give 73.7, about 6 points above zero-shot transfer from 63,981 English sentences. With 250 comments XLM-R passes the TF-IDF baseline trained on all 9,681 (79.4 against 75.6).

Starting from the English model is ahead at five of the six sizes, by 0.5 to 1.6 points, and behind by 1.6 at 250. The edge does not grow when Bengali data is scarce. For these two datasets, a few hundred Bengali labels are worth more than the whole English training set.

Fine-tuning the English model on Bengali keeps most of its English: 87 to 89 F1 up to 2,500 Bengali comments, falling to 84.4 after the full set. Training on both languages at once keeps it all (92.0 for the combined model). With the full training set the Bengali-only runs average 87.6 ± 0.6, close to the single-seed 87.4 in the main results despite the different schedule. The 36 runs took 47 minutes of training.

Limitations

SST-2 is movie reviews and SentNoB is social media comments, so zero-shot transfer measures a change of domain as well as language. Dropping SentNoB's neutral class makes the task easier than the paper's three-way setup, and the scores are not comparable with the paper's. The main results come from a single seed and the learning curve from three, which is too few to separate differences of under a point. XLM-R base is the only encoder tested; a Bangla-specific model such as BanglaBERT is the obvious comparison still missing.

Running it

The Colab notebook runs everything on a free T4. The data, baseline, three XLM-R runs and results table take about 50 minutes, and the learning curve takes about another hour. To run it locally with Python 3.10 or newer and a GPU:

git clone https://github.com/arif481/CrossLingual-Sentiment.git
cd CrossLingual-Sentiment
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m src.data_loader --language all
python -m src.baseline --run-all --output experiments/baseline
python -m src.train --mode zero_shot      # also low_resource, combined
python -m src.report
python -m src.learning_curve
