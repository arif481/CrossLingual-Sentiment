🌐 Cross-Lingual Sentiment Analysis

Binary sentiment classification for English and Bengali using multilingual transformers (XLM-RoBERTa)

About Demo Results Usage GitHub

About This Project

This project demonstrates cross-lingual sentiment analysis using multilingual transformer models. It supports sentiment classification in both English (high-resource) and Bengali (low-resource) languages.

🎯 Zero-Shot Transfer

Train on English data and evaluate on Bengali without any Bengali training examples.

📊 Low-Resource Learning

Fine-tune on limited Bengali data to establish a low-resource baseline.

🔗 Combined Training

Train on both languages for optimal multilingual performance.

Quick Start

Using the Model

from transformers import pipeline

# Load the model
classifier = pipeline(
    "sentiment-analysis",
    model="arif481/crosslingual-sentiment-model"
)

# English
result = classifier("This movie is fantastic!")
print(result)  # [{'label': 'positive', 'score': 0.98}]

# Bengali
result = classifier("এই সিনেমাটি অসাধারণ!")
print(result)  # [{'label': 'positive', 'score': 0.95}]

Running Locally

# Clone the repository
git clone https://github.com/arif481/crosslingual-sentiment.git
cd crosslingual-sentiment

# Install dependencies
pip install -r requirements.txt

# Prepare data
./scripts/run_preprocess.sh --demo

# Train model
./scripts/run_train.sh --mode combined --demo

# Run Streamlit app
streamlit run app/streamlit_app.py
